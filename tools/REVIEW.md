# 만화 대사·검색어 검토

`list.csv`의 한 행은 `img/{id}.png` 한 장에 대응한다. 사이트 검색은 `text`와 `keywords`를 읽으며, 뒤의 검토 열은 검색에 노출되지 않는다.

| 열 | 의미 |
| --- | --- |
| `text` | 그림의 제목·대사·읽을 수 있는 효과음을 컷 순서대로 전사. 컷 구분은 ` / ` |
| `keywords` | 대사에 있는 말과 그림의 주제·상황을 찾을 검색어. 공백으로 단어 구분 |
| `review_status` | 빈칸: 원본 대조 전. `partial`: 일부 대조했으나 `review_note`에 적힌 확인이 남음. `done`: 원본과 대사·검색어를 모두 검토함 |
| `review_note` | 판독이 어려운 글자나 남은 작업을 구체적으로 기록 |

현재 순차 검토 범위는 `0001`–`0090`이다. `0001`, `0004`, `0031`, `0058`, `0078`, `0081`, `0088`은 `partial`이고 83장은 `done`이다. **다음 순차 작업은 `0091`부터** 시작한다. 전체 1,137장 중 검토 상태가 빈 1,047장은 원본 대조 전이다. `partial`도 각 행의 메모를 보고 재확인한다. 숫자는 새 검토분을 반영할 때 갱신한다.

이후 작업자는 그림을 직접 보고 문구를 옮긴다. 보이는 철자와 욕설, 제목, 짧은 추임새도 임의로 순화하거나 고치지 않는다. 읽히지 않는 부분은 꾸며 넣지 않고 `partial`과 메모로 남긴다. 검색어에는 대사에 없는 장면의 주제나 통상적인 검색 표현을 보탤 수 있다. 한 편이 여러 장이면 각 이미지 행을 확인하고 `episode`, `page`는 유지한다.

새 이미지를 처리하는 `process.py`도 검토 열을 보존하고 새 행은 빈 상태로 만든다. CSV 열을 추가하거나 바꾸면 그 스크립트의 `COLS`도 함께 바꿔야 한다.
